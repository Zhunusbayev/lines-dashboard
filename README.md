# Дороги и связь: Афганистан, Пакистан, Туркменистан

Дашборд железных дорог, автодорог и ВОЛС: карта по статусам (действует / строится / планируется), карточки объектов с протяжённостью, подрядчиками, финансированием и источниками, выгрузка в PowerPoint, PNG и Excel.

Сайт: https://zhunusbayev.github.io/lines-dashboard/

Ссылка на конкретный объект: добавьте `#id` в конец адреса, например `…/lines-dashboard/#pk-a-m6`.

## Как обновить данные

Все объекты лежат в одном файле `data/projects.json`. Обновить можно прямо на GitHub:

1. Откройте `data/projects.json` и нажмите на карандаш (Edit).
2. Найдите объект по `"id"` или названию (Ctrl+F) и поправьте нужные поля.
3. Обновите `"updatedAt"` (дата в формате `2026-10-20`) и `"updatedBy"` (ваше имя), при желании добавьте строку в `"history"`.
4. Нажмите **Commit changes**. Сайт обновится через 1–2 минуты.

Если после правки сайт показывает «Не удалось загрузить данные», в файле ошибка синтаксиса JSON (чаще всего лишняя или пропущенная запятая). Откатите последний коммит или проверьте файл на jsonlint.com.

### Поля объекта

| Поле | Что это | Пример |
|---|---|---|
| `id` | Уникальный код, латиница и дефисы | `af-r-kz` |
| `mode` | Вид: `rail`, `road`, `fiber` | `rail` |
| `status` | `ok` — действует, `build` — строится, `plan` — планируется | `plan` |
| `countries` | Страны: `AF`, `PK`, `TM`, `OT` (прочие) | `["AF","TM"]` |
| `name`, `sub` | Название и короткое описание | |
| `route` | Трасса: города через « – », участки через «;» | `Герат – Шинданд; Кандагар – Спин-Болдак` |
| `km` | Число для итогов (0, если длины нет) | `91` |
| `kmText` | Как показывать протяжённость | `113–120` |
| `gauge` | Колея для ЖД, мм | `1520` |
| `who` | Подрядчик / исполнитель | |
| `money` | Финансирование | |
| `when` | Сроки и текущий статус работ | |
| `kz` | Участие Казахстана: `true` / `false` | |
| `sources` | Источники: `[{"t":"название","u":"https://…"}]` | |

Города для `route` берутся из `data/places.json` (координаты, русское название, синонимы). Если нужного города нет, добавьте его туда: `"ключ": [долгота, широта, "Название", ["синоним"], 0]`. Последнее число — подпись на карте: 1 — всегда, 2 — при приближении, 0 — без подписи.

## Файлы

- `index.html` — страница дашборда
- `data/projects.json` — реестр объектов
- `data/places.json` — справочник городов для трасс
- `data/basemap.json` — контуры стран для карты

Данные собраны по открытым источникам на октябрь 2026, трассы схематичные. По Пакистану показаны только основные магистрали и коридоры.
